# Google Cloud architecture icons

The seven files beside this notice are from the Google Cloud icon library,
downloaded from https://cloud.google.com/icons on 5 September 2026 (the
"Legacy console icons" package, `google-cloud-legacy-icons.zip`, which is the
set that carries a product icon for every service in the catalogue). They are
the 24 px colour icons: API Gateway, Cloud Functions, Cloud Run, Cloud SQL,
Pub/Sub, Cloud Storage and Memorystore.

The package carries no licence file. The page they are published on describes
them as:

> Official Google Cloud icons to build your own architectural diagrams or
> reference architectures.

> Welcome to the official library for Google Cloud product icons. Here you can
> find the Google Cloud product icons you need for your diagrams, technical
> documentation, and more.

Togen uses them for that purpose only. Google Cloud and the product names are
trademarks of Google LLC. Use of the icons is subject to Google's terms
(https://policies.google.com/terms) and brand guidelines
(https://about.google/brand-resource-center/).

Each file is the vendor's drawing with the title removed and the stylesheet
classes written out as attributes on the shapes, so that several icons can be
inlined on one page without their `.cls-N` rules overriding each other. The
mask and filter ids in the Pub/Sub icon are prefixed for the same reason. The
drawings themselves are unchanged.
