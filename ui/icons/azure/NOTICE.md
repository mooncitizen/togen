# Azure architecture icons

The seven files beside this notice are from the Azure architecture icons
package (`Azure_Public_Service_Icons_V24.zip`, July 2026), downloaded from
https://learn.microsoft.com/en-us/azure/architecture/icons/ on 5 September
2026. They are the service icons for API Management, Function Apps, Container
Apps, Azure Database for PostgreSQL, Service Bus, Storage Accounts and Cache
for Redis.

The package ships `Microsoft_Terms_of_Use.pdf`, which restates the terms on the
page the icons are downloaded from:

> Microsoft permits the use of these icons in architectural diagrams, training
> materials, or documentation. You can copy, distribute, and display the icons
> only for the permitted use unless granted explicit permission by Microsoft.
> Microsoft reserves all other rights.

The page also asks that the icons illustrate how products work together, that
the product name appears near the icon, that the icons are used as they appear
within Azure, and that they are not cropped, flipped, rotated, distorted or
used to represent another product. Togen uses them in architecture diagrams of
the user's own project, next to the node's type, and does not alter their
shape. Microsoft, Azure and the product names are trademarks of the Microsoft
group of companies.

Each file is the vendor's drawing with the title removed and the generated
gradient ids replaced by short prefixed ones, so that several icons can be
inlined on one page. The drawings themselves are unchanged.
