Togen studio

The canvas is not built yet. The server and its API are, so the UI has something to talk to.

Endpoint What it does
GET /api/project The project document
PUT /api/project Validates, then saves it
GET /api/layout Node positions and viewport
PUT /api/layout Saves them
GET /api/config Targets and output directory
POST /api/generate Writes the infrastructure code
GET /api/events Websocket, one message per file change
